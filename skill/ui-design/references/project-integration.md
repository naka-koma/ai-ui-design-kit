# プロジェクトとの統合

対象ルートの `.ui-design-kit.yml` で共通Skillの配置先と所有区分を確認する。`docs/design/README.md` から関連文書へ進み、正確な実装値はリンク先のコード・tokensを読む。

文書がない既存UIでは、CSS・テーマ・部品・代表画面から現状を調べる。証拠の不足を理由に、一般的なデザインシステムへ作り替えない。新規UIでは現在のタスクに必要な判断だけを確定する。

通常の製品作業で設計判断を更新する場合、対応するproject-owned文書に理由と根拠を記録する。共通Skillにプロジェクト固有の値やブランド規則を追加しない。

導入には中央のSETUP.md、共通Kit更新にはmanifestの配布元のSYNC.mdを使う。導入先から中央ファイルへの相対リンクや常時ネットワーク接続を必要としない。中央に接続できなくても、インストール済みSkillによる通常のUI作業は継続できる。
