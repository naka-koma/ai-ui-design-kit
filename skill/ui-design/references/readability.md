# 読みやすさ

コントラストの合格だけでは、文章やデータの読み取りやすさを保証しない。

- 実際の言語、長い見出し、桁の大きい数値、空欄で確認する。ダミーの短文だけで判断しない。
- 本文の文字サイズ、行間、行長、ウェイトを同時に見る。固定の万能値ではなく、表示幅・書体・用途に合わせる。
- 補助情報を薄くしすぎない。重要度が低くても読める必要はある。
- 表では比較軸を揃え、単位と精度を統一する。省略する場合は全文へ到達できる方法を用意する。
- 写真・グラデーション・透過の上の文字は、最も不利な背景で確認する。
- 拡大、文字間隔変更、翻訳、フォント読み込み失敗でも情報が欠落しないか確認する。

レビューでは「読みづらい」だけでなく、どの文字・背景・行長・密度が読み取りを妨げているか記録する。
