# 視覚的な階層

最初に何を見せ、次に何を理解させ、最後にどの判断・操作へつなぐかを定める。見出し、配置、余白、線、色の役割をそれに合わせる。素材単体だけでなく画面全体を見て、想定した順番で情報をたどれるか確認する。

- 強調を使う対象を絞る。全カードが同じサイズ・影・彩度だと優先順位が消える。
- 関連する情報を近づけ、無関係な情報の間に区切りを置く。カードを増やす前にグループ構造を見直す。
- 高密度画面は密度を維持しつつ、列、整列、見出し、選択状態で読解を支える。
- 情報の分離は余白だけに頼らず、枠、背景色、番号も役割に応じて使う。異なる構成でも、文字組み・整列・強調の共通ルールを保つ。
- 小画面では単純縮小ではなく、主タスクに沿って並びと優先度を見直す。視覚順とDOMの操作順を乖離させない。
- 主操作・副操作・破壊的操作を見分けられるようにする。状態を色だけに依存させない。

既存の構成が製品固有の仕事を支えている場合、流行のheroやカードグリッドへ機械的に置換しない。
